  2. Open the Story plan panel. Press Copy game header: its fingerprint must be sha256:5879152c8d428f840ff9919d5cfec074a954590e56d1987cda0c216793c12b7a.
  3. Copy the plan below, paste it into the Story plan box and press Validate: expected "Valid: no errors, 0 warnings".
  4. Press Apply. The inspector should show 16.73 s, 502 frames; plies 10 and 11 "eases in", ply 12 eases out to the full board, ply 13 zooms in after landing and returns to the full board (frames 426–434).

  6. Press Deactivate and check that Play/Export use your own range again (no plan marks).

Phase 5A: storytelling with an external AI

For Gemini or ChatGPT. Nothing here calls an AI; you paste the prompt yourself. Open on GitHub (rendered, with a copy button on the prompt block):

  • Prompt (copy-paste)
  • Storytelling guide
  • AI trials procedure and log
  • Examples (positive packets and validation cases)

Workflow: load the game → Copy game header → paste the prompt with the header, PGN and analysis into the AI → paste its JSON into Story plan → Validate → (Copy report back to the AI if needed) → Apply → read the inspector → Play / Export.
